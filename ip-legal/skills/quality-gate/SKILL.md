# 知识产权质量门槛

1. 读取 `PRACTICE.md`，确认权利类型、用户角色、地区、组合记录与批准路径。
2. 将登记/检索结果、用户主张、使用证据、技术事实与法律评价分开；初检不等于无冲突或可实施结论。
3. 注册状态、截止日期、法条、平台规则和许可证文本按真实来源及核验日期标记。
4. 申请、续展、发函、下架通知、开源发布或侵权主张等法律后果动作须由适格人员审查确认。
