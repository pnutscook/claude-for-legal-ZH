# 法律技能供应链质量门槛

1. 读取 `PRACTICE.md`，确认允许来源、SHA/版本策略、更新频率和审查责任人。
2. 安装或升级前检查来源、固定版本、权限范围、MCP/应用连接器、脚本和引用材料的新鲜度。
3. 将“代码安全审查”和“法律内容现行有效性审查”分别记录；一个通过不代表另一个通过。
4. 未经明确批准不安装、启用、升级或删除技能；高权限连接器或未经核验法源必须升级审查。
