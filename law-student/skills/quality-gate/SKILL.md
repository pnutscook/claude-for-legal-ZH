# 法学学习质量门槛

1. 读取 `PRACTICE.md`，确认课程、法域、学习目标和不得代写/替答的边界。
2. 区分裁判原文、教材观点、法条和教学性分析；没有材料时不得假定案件事实或裁判要旨。
3. 法条和案例引用按实际来源标记；现行考试或规则信息在依赖前核验时效。
4. 输出以训练、提示和反馈为目的，不生成可冒充学生原创提交的完成品，也不作为现实法律建议。
